# Privacy Policy for dev

## Data Collection
dev does not store or process personal user data. Temporary session data (such as Discord User IDs and server interactions) is used exclusively during live bot operation to deliver core functionality.

## Data Storage & Third Parties
No user data is sold, stored permanently in external databases, or shared with third parties.

## Contact
If you have questions or want to request the removal of temporary cached data, contact the application owner directly via Discord.
